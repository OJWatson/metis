# METIS

An easy-to-use Python package for timeseries surrogate modelling. Load a bank
of simulations, train and evaluate a neural surrogate, and save it for use in
other scripts or applications. Python functions and Hydra configurations use
the same implementation.

See the [documentation](https://ojwatson.github.io/metis/) for installation with
**uv** and worked examples using the **SIRDS epidemic model throughout**. The
tutorials include executed plots, downloadable Jupyter notebooks and an
**Open in Colab** option.

Start with [the Basics](https://ojwatson.github.io/metis/basics/motivation.html),
or go directly to [installation](https://ojwatson.github.io/metis/basics/installing_metis.html).
The distribution is `metis-surrogate`, imported as `metis`; install from this
repository as described in the guide. The PyPI package named `metis` is unrelated.
